# Безопасность

> **Статус проекта: alpha.** Мы делаем всё возможное, но проект написан быстро и выпущен «как есть», без гарантий безопасности. Используйте на свой страх и риск.
> Project status: alpha, provided as is, no security guarantees.

## Как сообщить об уязвимости
Пожалуйста, не создавайте публичный issue с подробностями. Откройте приватное сообщение: вкладка **Security** репозитория →
**Report a vulnerability**. Его видит только владелец репозитория. Опишите, что и как воспроизводится.
Если этой кнопки нет, создайте обычный issue с заголовком «Security: нужна приватная связь» **без технических подробностей**,
и мы договоримся, как передать детали. Ответ в разумный срок; исправление выйдет обновлением (`./ydl update`).

To report a vulnerability privately, use the **Security** tab of the repository → **Report a vulnerability**.
If it is not available, open a regular issue without technical details and ask for a private channel.

## Модель угроз (кратко)
`ydl` рассчитан на личное использование: один владелец, сервер дома или маленький VPS. Главные риски и меры:

| Угроза | Мера |
|---|---|
| Чужой в сети или интернете открыл страницу | вход по паролю, блокировка подбора, HTTPS на серверах в интернете |
| Чужой сайт в вашем браузере шлёт запросы на сервис (CSRF, DNS-rebinding) | заголовок `X-YDL`, проверка `Origin`/`Sec-Fetch-Site`, список разрешённых имён Host |
| Скачанный файл содержит скрипт (HTML/SVG) | такие файлы только скачиваются, ответ с CSP `sandbox` и `nosniff` |
| Вредоносное имя папки/файла со стороны Яндекса | имя очищается, пути проверяются, запись только внутри папки загрузок |
| Подмена адреса скачивания | разрешены только `https` и домены Яндекса, перенаправления проверяются |
| Диск забит скачиванием | загрузка приостанавливается при малом месте (`YDL_MIN_FREE_GB`) |
| Взлом самого сервиса | контейнер без привилегий, файловая система только для чтения, сервис не от root |

## Что не защищено / ограничения
- Пароли от публичных ссылок Яндекса хранятся на сервере открытым текстом (их нужно подставлять в запросы).
- Без включённого пароля сервис открыт всем, кто достучится до порта. Дома это ожидаемо; в интернете включайте пароль и HTTPS.
- Headless-Chromium внутри контейнера запускается с `--no-sandbox` (в контейнерах без дополнительных прав иначе нельзя) и открывает только страницы Яндекса.
- Автообновление выполняет код из вашего источника (git-репозиторий/архив/образ): доверяйте источнику и по умолчанию оно выключено.
- Сервис не заменяет резервные копии: удаление в менеджере файлов необратимо.
